# 🧰 Meus Scripts de Cibersegurança

Este repositório reúne uma coleção de scripts desenvolvidos para auxiliar em diversas tarefas relacionadas à cibersegurança, tanto ofensiva (Red Team) quanto defensiva (Blue Team). Os scripts são voltados para ambientes Linux/WSL e têm como foco a automação de tarefas técnicas, testes de segurança, análise de logs, escaneamento de redes e muito mais.

O objetivo é facilitar o dia a dia no terminal, otimizando tempo e ampliando a eficiência em atividades como:

- Coleta e análise de evidências
- Escaneamento de alvos
- Reconhecimento de rede
- Automação de tarefas repetitivas
- Monitoramento e resposta a incidentes

## 📜 Scripts disponíveis no momento

### 🔍 AnaliseDeLogs.sh
Script voltado para análise e extração de informações úteis em arquivos de log. Ideal para investigações e monitoramento de sistemas.

### 🌐 Scan de Rede ou porta.txt
Contém comandos e anotações para escaneamento básico de redes e portas. Serve como guia prático durante atividades de reconhecimento.

> Em breve, novos scripts serão adicionados para cobrir técnicas ofensivas e defensivas de cibersegurança, com foco em ambientes reais de Red Team e Blue Team.

## ⚙️ Requisitos

- Shell Bash
- Ferramentas como `grep`, `awk`, `nmap`, `netcat`, etc
- Permissão de execução (`chmod +x` nos scripts)

## 🚀 Como usar

```bash
chmod +x nome-do-script.sh
./nome-do-script.sh
```
